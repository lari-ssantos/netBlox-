# NetBlox Academy 3D — Construtor de Topologias de Rede

Jogo educativo 3D desenvolvido com HTML5, CSS3, JavaScript e Three.js.

## Como Executar
1. Extraia o arquivo `netBlox-academy-3d.zip`.
2. Abra o arquivo `index.html` diretamente no navegador (Chrome, Edge, Firefox) ou publique no GitHub Pages.

## Funcionalidades Incluídas
- **Avatar Roblox com Rosto Humano e Caminhada de Frente**: O personagem gira suavemente mantendo o rosto humano detalhado e o uniforme voltados para a direção do movimento (`WASD` ou Setas).
- **Vestiário de Skins e Roupas**: 4 personagens completos (*Técnico Jr. Lucas*, *Engenheira Maya*, *Cyber Kai* e *Dra. Sofia*) com roupas, crachás e acessórios 3D.
- **Inventário Hotbar (Teclas `1` a `9`)**:
  - `1` a `7`: Equipamentos de rede (`PC-PT`, `Laptop-PT`, `Printer-PT`, `Server-PT`, `Smartphone/Cafeteira IoT`, `Switch/Hub`, `HomeRouter-AC`).
  - `8`: Ferramenta de Cabo Ethernet.
  - `9`: Ferramenta Sem Fio / Bluetooth.
- **7 Fases Progressivas + Alerta de ERRO!**:
  1. Ponto a Ponto (Cabeado)
  2. Ponto a Ponto (Bluetooth)
  3. Estrela (Com Roteador)
  4. Barramento (Com Hubs)
  5. Anel (Com Switches)
  6. Malha (Com Switches)
  7. Rede Tipo Árvore (Híbrida)
